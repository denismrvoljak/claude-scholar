# docs/feedback/

Supervisor comments, examiner reports, peer feedback, and meeting notes — one file
per occasion, named by date.

Two rules make this folder pay off. Record feedback the day it arrives, while you
still remember what was meant rather than what was said. And when a piece of feedback
is a rule rather than a one-off correction, copy it into `.claude/rules/writing.md`
as well, so it is enforced on every future draft instead of remembered.

`/review` reads this folder and flags regressions — a fix that was made once and then
quietly undone.
