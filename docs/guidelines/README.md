# docs/guidelines/

Put your institution's own documents here before running `/onboard`: study
regulations, course description, assignment brief, supervisor's structure guide,
marking rubric, exam-form page. PDFs, screenshots, pasted text, and links all work.

Onboarding reads these and turns them into `docs/requirements.md`, with a source
recorded for every line. Everything downstream — budgets, review criteria, required
sections — comes from that file, so what you put here determines how much of the
setup is grounded in your actual rules rather than in defaults.
