# resources/theoretical/

Structured summaries of academic sources, one file per work, named
`<firstauthor_year>.md`. Written by `/save-material`.

A summary is worth more than a saved PDF because it records what the source is *for*
in this project: which claim it supports, where its evidence stops, and which other
sources it contradicts. That last field is the one that makes a literature review
into a synthesis.
