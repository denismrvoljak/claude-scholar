# sections/

One file per chapter. The order of the document is defined by `paper.md`, not by
filenames, so renaming a file means updating that manifest too.

The stub files here match the empirical-thesis profile. `/onboard` replaces them
with the chapter list your structure actually needs. Delete any you do not use —
an empty section file makes `/status` report progress that does not exist.

Each stub carries its heading skeleton and a note on what belongs in it. Keep the
note until the section is drafted; it costs nothing and stops a section drifting
into doing another section's job.
