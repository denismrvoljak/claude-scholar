# teach/

Exam preparation, built by `/teach`. Empty until you run it.

Written work usually ends in a room where you explain it out loud, with no notes
and often no AI, to someone looking for the soft spots. This directory is where
that gets rehearsed.

| File | Holds |
|------|-------|
| `MISSION.md` | The exam: date, format, examiners, what they are known to probe, and what success looks like |
| `INVENTORY.md` | Every examinable concept, method, number, and citation, with its tested status |
| `RESOURCES.md` | Where each concept is defined in this project's own files |
| `NOTES.md` | What has been learned about how this learner learns |
| `questions.md` | The mock question bank: question, the trap, a strong answer, the follow-up |
| `lessons/` | One self-contained HTML lesson per session |
| `records/` | What was tested each session and what actually stuck |

The records are the point. They are what makes the fifth session sharper than the
first, and they are the only honest measurement of readiness you will have —
self-rated confidence tracks recognition, not recall, and the difference only
shows up when someone asks you a question out loud.
